# ZenBank Deployment Portfolio Summary

## Project Goal

Build a microservices-based banking-style platform that looks enterprise-ready for interviews and portfolio presentations.

## Core Components

- Auth service for JWT-based authentication
- Order service for business workflows
- Inventory service for stock availability
- Payment service for billing flows
- API gateway for centralized routing
- Eureka for service discovery
- Kafka for asynchronous messaging

## DevOps and Cloud Coverage

- Docker for containerization
- Docker Compose for local orchestration
- Terraform for infrastructure as code
- AWS ECS for container deployment
- ALB for traffic distribution
- Route 53 and ACM for DNS and HTTPS
- CloudWatch and autoscaling for monitoring and resilience
- Secrets Manager for sensitive configuration
- Kubernetes deployment example for orchestration comparison

## Interview Story

This project demonstrates:

- microservices architecture
- API gateway security
- event-driven communication
- cloud deployment design
- CI/CD readiness
- infrastructure automation

## Suggested Presentation Flow

1. Explain the architecture and service responsibilities
2. Show how requests flow through the gateway
3. Highlight Docker and Kubernetes readiness
4. Explain AWS deployment path with ECS, ALB, and monitoring
5. Conclude with IaC and DevOps practices
