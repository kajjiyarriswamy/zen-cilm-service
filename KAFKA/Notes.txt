1. What is Kafka?

Kafka is a distributed messaging system used to transfer data between applications in real-time.

Simple Definition

Kafka acts like a post office that delivers messages from one application to another.

Real World Example

Imagine Swiggy.

Customer places an order.

Customer
    |
    |
Order Service
    |
    | Order Placed
    |
   Kafka
    |
--------------------------
|           |            |
Restaurant  Payment   Notification
 Service     Service      Service

Instead of calling every service directly,

Order Service simply sends one message to Kafka.

Kafka distributes it to all interested services.

Advantages

Loose coupling
Faster
Scalable
Reliable

18. Producer Acknowledgements (acks)
acks=0

Producer doesn't wait.

Fastest.

Possible data loss.

acks=1

Leader confirms.

Most commonly used.

acks=all

Leader + Followers confirm.

Safest.

Slowest.

19. Delivery Semantics
At Most Once

May lose messages.

No duplicates.

At Least Once

No message loss.

Duplicates possible.

Exactly Once

No loss.

No duplicates.

Used in financial applications.

One partition can be consumed by only one consumer within the same consumer group.
One consumer can consume multiple partitions.
If consumers > partitions, extra consumers remain idle.
If partitions > consumers, some consumers handle multiple partitions.
Different consumer groups can read the same partition independently because each group maintains its own offsets.
