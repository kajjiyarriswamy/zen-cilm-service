# DevOps Interview Cheat Sheet

## Must-know concepts

- Docker: image, container, Dockerfile, port mapping
- ECS: cluster, task definition, service, load balancer
- Fargate: serverless containers
- ECR: container registry
- ALB: traffic distribution
- Route 53: DNS
- CloudWatch: logging and monitoring
- IAM: access control
- Terraform: infrastructure as code
- CI/CD: automate build and deploy
- Secrets: use Secrets Manager or SSM Parameter Store

## Short interview answers

- What is Docker? -> Docker packages applications into containers for consistent deployment.
- What is ECS? -> ECS is AWS’s managed container orchestration service.
- What is Fargate? -> Fargate runs containers without managing servers.
- What is Terraform? -> Terraform provisions cloud infrastructure using code.
- What is CI/CD? -> CI/CD automates testing and deployment.
- Why use ALB? -> ALB distributes traffic and improves availability.
- Why use CloudWatch? -> CloudWatch helps monitor health and logs.
- Why use Secrets Manager? -> It keeps sensitive data secure and centralized.
